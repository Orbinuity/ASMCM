Compile & Run ASMC scripts

### On Linux / Mac

```bash
curl -fsSL https://raw.githubusercontent.com/Orbinuity/ASMCM/main/install.sh | sh
```

### On Windows

```powershell
irm https://raw.githubusercontent.com/Orbinuity/ASMCM/main/install.ps1 | iex
```
